# Saksham Pathshala — Three Unique NGO Website Directions

This package intentionally contains three substantially different visual/UX systems. They all use the supplied Saksham Pathshala content, but each version is designed around a different communication intent:

- V1 — Impact Editorial: trust + mission + action
- V2 — Learning Hub: learner utility + program discovery + support
- V3 — Human Stories: emotional storytelling + campaign-style narrative

Every version includes the seven requested pages and a Page Versions dropdown in its header, allowing side-by-side comparison of V1/V2/V3 for the current page.

## Pages
Home, About Us, Learning Programs, Resource Library, Live Classes, Join Saksham, Help Desk.

## Launch notes
Replace the remote stock photography with approved Saksham photography; replace placeholder teacher/timing/contact fields with verified information; connect forms to the final registration/CRM workflow; add verified impact figures only when provided by the NGO.
